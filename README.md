# geo-ipwhois.sh - A GeoIP Lookup Script

**Function:**&nbsp;&nbsp;Uses https://ipwhois.is to provide GeoIP lookups (1000/day Free)

**Usage:**&nbsp;&nbsp;geo-ipwhois.sh [-flags] ipaddress<br />
&nbsp;&nbsp;&nbsp;&nbsp;• If no IP is given, user's external IP will be used

**Flags:**<br />
&nbsp;&nbsp;&nbsp;&nbsp;-a	Display all GeoIP output<br />
&nbsp;&nbsp;&nbsp;&nbsp;-h 	Show this help screen<br />
