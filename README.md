# geo-ipwhois.sh - A GeoIP Lookup Script

Function: Uses https://ipwhois.is to provide GeoIP lookups (1000/day Free)

Usage: geo-ipwhois.sh [-flags] ipaddress<br />
    If no IP is given, user's external IP will be used

Flags:<br />
    -a	Display all GeoIP output<br />
    -h 	Show this help screen<br />
